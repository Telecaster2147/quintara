# 首次使用流程

1. 在“研究边界”页逐项阅读用途、数据、模型、决策责任和本地隐私说明，再主动确认。
2. 在“工作流程”页了解完整性检查、本机 CPU 训练、参考结果核对和结果复查顺序。
3. 在“数据来源”页三选一：安装包自带开发者数据、从 BaoStock 在线初始化、自己的 CSV。
   自带数据先核对清单、大小和 SHA-256；BaoStock 先展示目标交易日、股票池、字段、复权、
   预计下载量和保存位置；CSV 会检查字段、单位、代码、日期、重复键和历史长度。
4. 在“文件位置”页确认安装包数据、当前工作目录和活动数据路径。选择新工作目录后，
   新路径会立即显示，并在设置页持续保留。
5. 在“完成检查”页确认声明、活动数据、工作目录和来源均已就绪，然后进入工作台。
6. 打开“训练”，使用默认的稳健平衡策略开始本机 CPU 训练。开发者数据使用完整可用
   历史，并在结果发布前核对五只股票、顺序、权重和参考 CSV 哈希。
7. 在“结果”页复查名称、代码、权重、数据截止日、当前路径和研究风险，再选择导出位置。

CLI 等价流程：

```bash
quintara bootstrap
quintara consent accept
quintara doctor
quintara data update --pit-membership-csv ./pit_membership.csv
quintara run --years 5 --strategy balanced
```

已有活动数据后，数据页主按钮为“一键更新至最新交易日”。应用先使用 BaoStock 交易日历
与实际日线探测确定完整截止日，再展示当前/目标版本、证券数量、字段、单位、后复权口径、
预计下载量和完整工作路径。确认后从当前截止日后的第一个有效交易日增量下载，完成键、
OHLC、PIT 区间和合同校验后才原子发布。源 CSV 与安装包数据保持原样；安装包压缩包留在
应用目录树的 `data/developer/`，派生活动数据、模型与结果保存在用户选择的工作目录。
