# 长任务、退出与故障恢复

下载、检查、更新、训练和预测由 `JobCoordinator` 使用同一任务 ID、JSON snapshot、追加 JSONL 事件和单写入者锁管理。幂等键阻止重复启动。进度 DTO 同时支持字节/条目总量、阶段型进度、速率、耗时和仅在稳定时出现的剩余时间。

协作停止只在任务 spec 的停止点生效；界面先显示“正在停止”。超过宽限时间可确认强制结束，未跨过 publish 边界的 staging 会清理。已发布内容不被回滚为半成品。GUI 关闭时任务可留在后台或请求停止；CLI 的 SIGINT/SIGTERM/SIGHUP 进入同一取消语义并保留退出码。

启动扫描把中断的运行任务标记为 `RECOVERED`：下载给出续传，其他计算给出重新开始；孤立 staging 隔离或清理。错误摘要隐藏主目录与内容根，保留错误码、影响、恢复动作；技术抽屉可复制日志，诊断导出只写本机并替换敏感路径。
