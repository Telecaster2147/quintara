# Quintara 0.2.1 发布说明

Quintara 0.2.1 改进首次数据准备、日常更新、Windows 启动体验和离线复现流程。

## 训练与界面体验

- 训练页实时展示检查数据、准备特征、CPU 训练、生成排名、计算摘要、保存结果和完成状态，并持续显示进度与已用时间。
- 训练或数据操作遇到异常时，页面保留用户可读的处理建议、当前阶段和可展开的技术详情；应用日志写入本地工作目录。
- CSV 导入、结果导出和工作目录迁移在后台执行，导航和按钮会先给出视觉反馈。
- 结果摘要在训练完成时预先计算，首页与结果页不再重复读取完整行情文件。
- 超出窗口高度的页面显示常驻右侧滚动条，最小窗口下也能抵达底部操作区。
- BaoStock 更新预览在小窗口中独立滚动，底部“返回调整”和“确认并开始”操作始终可见；数据页同步显示更新阶段日志、进度、耗时与完成/失败状态。

## 三种数据来源

- 首次向导现在明确提供三种互斥选择：安装包自带开发者数据、BaoStock 在线初始化、用户 CSV。
- 没有活动数据时，数据页同时提供三条准备入口；准备完成后主操作统一为“一键更新至最新交易日”。
- 安装包数据保持在应用目录树的 `data/developer/`，用户 CSV 保持原样；联网更新发布为新的 BaoStock 派生版本。

## BaoStock 一键初始化与更新

- 更新前展示当前版本与截止日、实际目标交易日、股票池、字段、单位、后复权口径、预计下载量、磁盘预算和完整保存位置。
- 目标截止日由 BaoStock 交易日历和实际日线可用性共同确定；增量从当前截止日后的第一个有效交易日开始。
- 沪深300路线会续接历史成员区间，记录加入与移出，并保留退市证券的历史资料；自定义股票池严格跟随当前代码集合。
- 运行过程展示连接、证券资料、股票池、行情、扩展字段、校验和发布阶段。下载检查点绑定代码、日期、字段、复权及股票池身份。
- 登录、查询、字段、单位、复权、PIT、重复键、OHLC、磁盘或取消检查出现异常时，上一活动版本持续可用。

## 离线开发者数据与结果核对

- Windows 安装版、Windows 便携 ZIP 与 Linux 压缩包附带同一完整开发者数据包。
- 使用该固定数据完成本机 CPU 训练时，应用核对五只股票、顺序、权重和参考 CSV 哈希，核对通过后展示结果。
- Windows 与 Linux 使用统一的 CSV 换行格式，同一固定数据的参考结果哈希保持一致。
- 每个可修改路径会在相关页面持续显示，迁移工作目录后立即刷新并跨启动保留。

## Windows 桌面启动

- 桌面与开始菜单使用无控制台窗口的 GUI 入口，打开应用时不再常驻 PowerShell 或控制台窗口。
- CLI 保留独立终端入口、标准输出、退出码和管道行为。
- 应用、任务栏、安装器、桌面和开始菜单使用同一套 Quintara 多尺寸图标。

## 下载内容

- `Quintara-Windows-x64-Setup.exe`：Windows 安装版，包含应用旁开发者数据。
- `Quintara-Windows-x64-Portable.zip`：Windows 便携版，解压后保持 `data/developer/` 相对目录。
- `Quintara-Linux-x86_64.tar.gz`：Linux GUI、CLI 与开发者数据。
- `SHA256SUMS.txt`：全部公开制品的 SHA-256 校验值。

Quintara 用于本地量化研究。历史数据与模型输出存在局限，结果不代表未来表现，也不构成个性化投资建议或收益承诺。
