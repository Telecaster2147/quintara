# Quintara v2 用户指南

## 首次启动与研究边界

首次启动按五步完成：确认“仅供本地研究”声明、检查电脑、在 **Quintara 标准数据** 与 **自己的 CSV** 之间二选一、确认本地存储、进入工作台。中途关闭会保存步数；环境检查之后可“稍后完成”；设置页可重新打开向导。声明文字或哈希版本更新后需要再次确认。

标准数据在联网前显示供应方身份、许可、版本、字节数、预计双倍暂存空间和 PIT 闭包状态，用户分别确认许可与传输。CSV 始终在本机只读检查，原文件不被修改；导入 generation 保存源 SHA-256、字段映射、单位声明和问题报告。

## 数据与存储

数据页显示活动 generation、截止日、覆盖股票数、来源/许可、完整性、磁盘大小和本地位置。更新先写 staging、逐文件校验，再原子切换 `active.json`。失败内容进入 quarantine，原活动版本继续可用。迁移内容根采用“预算—暂存复制—generation 校验—切换”，旧目录保留到用户确认清理。

BaoStock 更新在登录后按日期增量拉取行情、上市信息和估值字段。大规模行情传输前先确定 PIT 成分计划；PIT 不可得时可以继续上一 PIT 版本，或显式确认 `NON_PIT_FALLBACK` 的幸存者偏差。重复日期按键去重，字段漂移、成员失败与来源冲突会停止发布。

## 股票池与训练

股票池支持搜索、筛选、单只增删与 CSV 批量导入；可保存多个命名池，但只有一个活动池。列表显示名称、六位代码、交易所、数据覆盖和特殊状态。自定义清单与每个历史截面都至少 100 只；模型、结果和历史按股票池及路线隔离。

训练页先显示声明、数据、活动股票池与内核就绪状态。默认策略是 **稳健平衡**，另有积极与保守策略；高级参数默认折叠。CPU 是权威结果路径，NVIDIA GPU 仅作显式实验探测。训练、停止与发布边界使用同一个任务 ID。

## 结果、历史与导出

结果页优先展示 Top-5 的名称、代码、交易所、固定权重和模型评分，并给出策略说明、单股解释、数据质量与研究风险。`NON_PIT_FALLBACK` 徽标和幸存者偏差警告持续显示。“数据与模型依据”列出 run、data generation、model、kernel、label、路线和声明版本。

历史可按日期、股票池、策略和路线筛选。CSV 使用 UTF-8 原子写入；目标已存在时先确认覆盖。导出含 `research_only`、风险提示、路线与相邻 provenance manifest，后者记录内容 SHA-256。
