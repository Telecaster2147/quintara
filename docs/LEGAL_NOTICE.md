# 数据与研究边界声明

Quintara 是本地量化研究软件，用于整理数据、训练模型和复查历史结果。软件输出是
研究记录，不构成收益承诺、个性化投资建议或自动交易指令。历史拟合、模型评分和
单次 Top-5 结果均不代表未来表现。

历史数据可能存在缺失、复权差异、停牌、退市、成分变更和发布时间差异。使用者需要
核对数据版本、来源、字段与单位，并在采纳研究结论前独立核对证券状态、交易规则、
流动性、费用、个人风险承受能力和适用要求。中国证监会的投资者教育材料强调充分认识
市场风险、了解并遵守市场规则和审慎投资；《证券法》投资者保护章节也要求服务提供方
充分揭示风险。参考资料：

- [中国证监会：证券市场程序化交易管理规定（试行）](https://www.csrc.gov.cn/csrc/c100028/c7480577/content.shtml)
- [中国证监会：《证券法》投资者保护章节](https://www.csrc.gov.cn/fujian/c105584/c1288028/content.shtml)

PIT 基线、CUSTOM_UNIVERSE 和 NON_PIT_FALLBACK 是不同研究身份；NON-PIT 结果会
带显著路线标识，不应被当作 PIT 生产基线引用。

数据、模型和结果默认保存在用户选择的本机工作目录。遥测保持关闭；只有用户主动发起
数据更新或版本检查时，软件才执行相应联网操作。安装包自带开发者数据固定在随包版本，
其截止日期和文件位置会在向导与数据页显示。
