## Purpose

规定新用户首次进入 Quintara 时如何完成风险确认、环境检查和数据来源选择，并让中断后的流程可理解、可恢复、可重新进入。

## ADDED Requirements

### Requirement: 首次启动采用任务向导
**FRC-001** Quintara SHALL 在新用户目录中先展示中文首次使用向导，按“研究边界—工作流程—数据来源—文件位置—完成检查”组织，并在每一步显示目的、当前状态和下一步；训练入口仅在数据达到可训练状态后启用。

#### Scenario: 新用户进入产品
- **WHEN** 用户首次启动桌面应用
- **THEN** 应用展示风险声明和五步进度，而非原始配置、manifest 或 JSON

#### Scenario: 数据尚未就绪
- **WHEN** 用户跳过向导或数据准备尚未完成
- **THEN** 首页展示继续准备数据的主操作，并在训练入口旁说明当前缺少的条件

### Requirement: 风险声明版本化确认
**FRC-002** Quintara SHALL 要求用户主动确认当前版本的研究用途与投资风险声明；声明 SHALL 分别解释用途、数据、模型、决策责任、本地隐私与联网边界，并在本地记录声明版本、各分节哈希、应用版本和确认时间；声明版本变化后重新请求确认。

#### Scenario: 当前声明尚未确认
- **WHEN** 用户尝试进入数据准备后的功能
- **THEN** 应用引导用户阅读并确认声明后继续

### Requirement: 环境摘要面向普通用户
**FRC-003** Quintara SHALL 自动检查操作系统、CPU、内存、可用磁盘、NVIDIA GPU/驱动和 GUI 平台，并以“可用、需关注、实验性”呈现结论；完整版本号、插件路径和诊断日志放入可展开详情。

#### Scenario: CPU 可用而 GPU 条件不完整
- **WHEN** 环境检查发现 CPU 路径满足要求且 GPU 探测失败
- **THEN** 向导将 CPU 标记为可用、GPU 标记为实验性关注项，并允许继续 CPU 流程

### Requirement: 用户显式选择数据来源
**FRC-004** Quintara SHALL 提供三个互斥的数据来源选择：“安装包自带开发者数据”“从 BaoStock 初始化”和“使用自己的 CSV”；选择页 SHALL 明确区分来源与活动 generation，展示来源说明、版本或文件、覆盖范围、预计体积、安装位置、活动数据位置和后续更新方式，且不会在确认前开始大规模数据处理。

#### Scenario: 选择供应方数据
- **WHEN** 用户选择“安装包自带开发者数据”并确认
- **THEN** 应用校验安装目录旁的数据包，并在用户工作目录建立活动数据

#### Scenario: 选择用户 CSV
- **WHEN** 用户选择 CSV 文件并确认
- **THEN** 应用先执行只读可训练检查并展示通过项、阻断项及行列定位

#### Scenario: 从 BaoStock 初始化
- **WHEN** 用户选择 BaoStock 并请求初始化计划
- **THEN** 应用展示实际目标交易日、历史股票池、字段、复权、单位、预计证券数、下载量、磁盘与完整保存路径，经确认后在暂存区构建首个活动 generation

### Requirement: 向导状态可恢复
**FRC-005** Quintara SHALL 将已确认步骤、选定来源和任务引用原子化保存在本地；用户可以跳过、关闭后继续，或从设置重新打开向导，恢复时先核验外部文件和任务状态。

#### Scenario: 下载中退出后重开
- **WHEN** 用户在供应方数据下载期间关闭应用并再次启动
- **THEN** 向导展示已保存进度、上一可用数据版本和“继续下载/重新开始”动作

#### Scenario: 外部 CSV 已被移动
- **WHEN** 恢复向导时原 CSV 路径已失效
- **THEN** 应用保留之前的检查记录并请求重新选择文件，不把该来源标记为就绪

### Requirement: 可修改路径持续可见
**FRC-006** Quintara SHALL 在首次向导以及首页、数据、结果、历史和设置等相关页面持续显示当前工作目录、安装包数据位置、活动数据位置、最近 CSV 导入位置和最近结果导出位置；路径 SHALL 支持选择与换行，修改后立即刷新并跨启动保留。

#### Scenario: 用户迁移工作目录
- **WHEN** 用户选择新工作目录且 generation 校验通过
- **THEN** 应用立即切换服务内容根并在向导与设置页显示新路径，同时保留旧目录等待用户后续处理

#### Scenario: 用户导入或导出文件
- **WHEN** 用户完成 CSV 导入或结果导出
- **THEN** 对应页面显示本次完整路径，并在下次启动后继续显示
